# Roadmap: Aurora v1.21 Operator Config

**Status:** Complete ✅
**Milestone:** v1.21 Operator Config
**Started:** 2026-08-23

## Overview

The oracle scheduler poll cadence was hardcoded to 1s in `cmd/api`, so
operators could not tune it. v1.21 makes it config-driven.

## Success Criteria

- [x] Expose `oracle.scheduler.checkInterval` (default 1s) via a config
      accessor and wire it into `cmd/api`; per-source `Interval` still gates
      when each feed is due.
- [x] Config default + override test.
