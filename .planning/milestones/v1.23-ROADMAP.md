# Roadmap: Aurora v1.23 Voting Results API

**Status:** Complete ✅
**Milestone:** v1.23 Voting Results API
**Started:** 2026-08-23

## Overview

The CLI exposed `voting results` but the REST API had no results surface.
v1.23 adds a results endpoint closes the CLI/API parity gap.

## Success Criteria

- [x] `GET /api/v1/voting/results/{id}` returns the session's per-candidate tally
      plus a `total_votes` (deleted candidates count 0), via `GetResultsUseCase`.
- [x] Use-case + handler tests (success and session-not-found).
