# Roadmap: Aurora v1.87 API-Consistency + Latent-Concurrency Sweep

**Status:** Complete
**Milestone:** v1.87 API-consistency + latent-concurrency sweep
**Started / Closed:** 2026-08-29 (round 101)

## Overview

Round 100's parallel audit seeded the v1.86 infra-robustness fixes and left a
verified-but-deferred backlog: three latent/visibility defects across the REST
API and the event infrastructure. Round 101 drained that backlog. Each fix was
driven test-first (a regression test that fails on the pre-fix code, verified
by stashing the fix), then confirmed by the full `go test ./... -race` suite.

## Work items

1. **SyncEventBus self-deadlock (TASK-138, ISS-128, stability).** `Publish`
   invoked subscriber handlers while holding the read lock, so a handler that
   called `Subscribe`/`Unsubscribe` (write lock) during publish deadlocked the
   whole bus — a latent trap in the used public API. `Publish` now snapshots
   the handler lists under the read lock and runs them outside it, preserving
   per-publish ordering and the all-or-nothing early-return contract. Two new
   tests (self-unsubscribe and subscribe-during-publish) deadlock the old code.
2. **Unknown-resource status consistency (TASK-137, ISS-130, correctness).**
   `GET /api/v1/oracle/query` returned 200 `[]` for a missing or unknown
   source; `GET /api/v1/oracle/latest` could 500 on a known-but-empty source
   (the sqlite repo returned the generic, unclassified `ErrNotFound`);
   `GET /nft/{id}/history` returned 200 `[]` for a nonexistent id. Now: missing
   `source` → 400 (parity with `/latest`), unknown source → 404
   `SOURCE_NOT_FOUND` (both repos), sqlite `GetLatestData` returns `(nil, nil)`
   per the interface contract (known-but-empty stays 200 `{data:null}`), and
   NFT history on a nonexistent id → 404 `NFT_NOT_FOUND` — all consistent with
   the `/sources/{id}` and `/nft/{id}` 404 behavior.
3. **MetricsRegistry lazy-init race (TASK-139, ISS-131, stability).**
   `Server.MetricsRegistry()` was check-then-set with no lock; concurrent
   callers on a Server built without `NewServer` could create two registries
   and split the request counters. Now sync.Once-guarded; the 64-goroutine
   regression test races on the old code.
