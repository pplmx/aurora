# Roadmap: Aurora v1.62 Token Duplicate-Symbol Guard

**Status:** Complete ✅
**Milestone:** v1.62 Token duplicate-symbol guard
**Started:** 2026-08-23

## Overview

A token's ID is its symbol, and `TokenRepository.SaveToken` uses `INSERT OR
REPLACE` keyed on that ID. `TokenService.CreateToken` performed no existence
check, so creating a second token whose symbol was already taken silently
overwrote the first token's row — and its owner balance — losing the first
token's data (name, supply, owner). Verified against the domain mock:
`CreateToken "DUP"` twice left only the second token.

## Success Criteria

- [x] `CreateToken` checks for an existing token id (the requested symbol) and
      returns `ErrTokenExists` instead of overwriting.
- [x] New sentinel `token.ErrTokenExists`; API handler maps it to HTTP 409
      (`TOKEN_EXISTS`).
- [x] Regression test `TestCreateToken_RejectsDuplicateSymbol`: a second create
      with the same symbol returns `ErrTokenExists` and the first token stays
      intact.
- [x] `go build ./...` green; `go test -race ./...` green; `gofmt`/`go vet` clean.
