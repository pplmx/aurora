# Roadmap: Aurora v1.53 Web Self-Containment — Remove Unused External htmx

**Status:** Complete ✅
**Milestone:** v1.53 Web Self-Containment (remove unused external htmx)
**Started:** 2026-08-23

## Overview

All seven shipped web pages loaded the htmx library from the external CDN
`https://unpkg.com/htmx.org@1.9.10`, but nothing used it — there were no `hx-`
attributes and no `htmx.*` calls anywhere under `web/`. Every page carried dead
third-party weight that broke offline use, depended on external uptime, and
widened the supply-chain/provenance surface. v1.53 removes it and locks the
property with a regression guard.

## Success Criteria

- [x] No shipped `<web>` page references the htmx library (all 7 pages cleaned).
- [x] `TestWebUINoUnusedHtmx` asserts no shipped HTML page contains "htmx",
      guarding against silent reintroduction.
- [x] `go build ./...` green; `go test -race ./...` green; `gofmt`/`go vet` clean.
