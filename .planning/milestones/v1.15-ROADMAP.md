# Roadmap: Aurora v1.15 Oracle Scheduled Fetching

**Status:** Complete ✅
**Milestone:** v1.15 Oracle Scheduled Fetching
**Started:** 2026-08-23

## Overview

Oracle data sources carry a refresh `Interval` (seconds) that was stored and
exposed through the API/CLI but never acted on — nothing actually refreshed
sources on their configured cadence. v1.15 makes the interval real by adding
an in-process scheduler that periodically fetches enabled sources.

## Success Criteria

- [x] Add an in-process scheduler that polls enabled sources and fetches those
      whose interval has elapsed (failed fetches retried next pass).
- [x] Wire the scheduler into the server (`Server.StartOracleScheduler`,
      cancellable) and start it on `cmd/api` boot.
- [x] Derive last-fetch time from the latest recorded data so a restart does not
      re-fetch every source immediately.
