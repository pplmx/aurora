# Roadmap: Aurora v1.82 Report-the-Truth & Dead-Code Sweep

**Status:** Complete ✅
**Milestone:** v1.82 bug-fix / feature-enhancement (ISS-107..109)
**Started / Closed:** 2026-08-27

## Overview

After v1.81 closed the integrity & client-error sweep, the graph had no
active tasks — the loop entered deep-dive mode. Three verified defects plus
one dead-code cleanup surfaced from the v1.81 hand-off notes and direct
inspection:

1. A committed token operation whose post-commit audit publish fails is
   **reported as an operation failure** — the single most dangerous class
   this milestone fixes, because a retry repeats already-committed money
   movement (Transfer/Mint/TransferFrom/Burn/Approve/Allowance).
2. `BackupService.Restore` lacks the same-file guard `Create` gained in
   v1.71 (restoring from the live data dir self-clobbers as a silent
   no-op), and its pre-restore safety copy is a raw `.db` copy that omits
   uncheckpointed committed WAL frames — a regret-undo could resurrect a
   DB missing recent commits.
3. The `internal/app` composition root (`Wire`/`App`) is production-dead —
   nothing imports it, only its own test keeps it compiled — and it
   re-carries the phantom data-dir side effect removed in v1.80 (ISS-095).
   Retired, plus a stale `oracle_test.go` comment that still claims
   `PersistentPreRunE` runs `app.Wire`.

Parked with a recorded decision (not in scope): ISS-084 phantom on-chain
blocks (DEC-002), and the same-second UUID event ordering — the events
table ties on random UUID v4 within a second; ordering is only approximate
anyway (IDs are created before commit), so fixing it needs a schema/ID
migration that is not justified by the marginal ordering gain. Revisit
with a ULID/insertion-sequence design in a future milestone.

## Work items

1. **Committed op never reported as failed (TASK-117, ISS-109, correctness).**
   Add `tokenerrors.ErrAuditPublishFailed` sentinel; wrap the post-commit
   publish sites in `internal/domain/token/service.go`
   (Mint/Transfer/TransferFrom/Burn/Approve/IncreaseAllowance/
   DecreaseAllowance). CLI detects it via `errors.Is` and prints a distinct
   do-not-retry warning (exit != 0, exact message, no `❌` failure framing).
   API classifier maps it to `AUDIT_PUBLISH_FAILED` with a safe static
   message so clients never auto-retry a committed write.
2. **Backup Restore hardening (TASK-116, ISS-108, stability).**
   Refuse to restore when a backup `.db` aliases a live source DB
   (`os.SameFile`, mirroring the v1.71 `Create` guard); snapshot each live
   DB into `.pre_restore` via online `VACUUM INTO` (WAL-complete, like
   `Create`) instead of a raw `io.Copy`, and abort before clobbering if the
   safety snapshot cannot be built. Regression tests for both.
3. **Retire dead composition root (TASK-115, ISS-107, maintainability).**
   Delete `internal/app/wire.go` + `internal/app/wire_test.go`; fix the
   stale `cmd/aurora/cmd/oracle_test.go` comment that claims
   `PersistentPreRunE` still runs `app.Wire`.
