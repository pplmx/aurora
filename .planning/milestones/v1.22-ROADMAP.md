# Roadmap: Aurora v1.22 Web UI Parity

**Status:** Complete ✅
**Milestone:** v1.22 Web UI Parity

## Overview

The web UI covered Dashboard, Lottery and Voting but had no Token or Oracle
pages. v1.22 adds both, wired to the real REST API, and enforces
page↔endpoint parity via the web contract test.

## Success Criteria

- [x] Token page (create / balance / mint) and Oracle page (list sources /
      fetch / query), built on Alpine.js, using only real REST endpoints.
- [x] Dashboard nav includes both new pages; web contract test now resolves the
      pages' endpoints (query-string-aware) and the served-with-API-key render
      test covers them.
