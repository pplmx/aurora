# Roadmap: Aurora v1.16 Operator Reliability — Feed Health Observability

**Status:** Complete ✅
**Milestone:** v1.16 Operator Reliability
**Started:** 2026-08-23

## Overview

v1.15 added scheduled oracle fetching but the scheduler only logged failures —
operators had no counters to monitor feed health. v1.16 makes scheduled
oracle feeds observable: per-source attempts/successes/failures exposed in
Prometheus text format, so a silently-failing feed is visible.

## Success Criteria

- [x] Track per-source fetch stats (attempts, successes, failures, last error,
      last success time) in the scheduler (thread-safe).
- [x] Expose them as Prometheus text at a public `/metrics/oracle` endpoint
      (race-safe, nil-safe), with stats + endpoint regression tests.
