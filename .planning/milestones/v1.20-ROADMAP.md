# Roadmap: Aurora v1.20 Backup Restore Safety

**Status:** Complete ✅
**Milestone:** v1.20 Backup Restore Safety
**Started:** 2026-08-23

## Overview

`aurora backup restore` copied a backup over the live databases without any
integrity check, so a corrupt/truncated backup silently clobbered a good DB
(recovery only via the hidden `.pre_restore` dir). v1.20 refuses to restore a
backup that fails integrity verification.

## Success Criteria

- [x] Restore verifies the backup (checksum + DB validity) before touching any
      live file; a corrupt backup is rejected with "refusing to restore".
- [x] Tests: restore of a valid backup succeeds; corrupt-backup and
      directory-as-DB backups are refused and the live DB is untouched.
