# Roadmap: Aurora v1.63 Oracle Path-Extraction Fail-Closed

**Status:** Complete ✅
**Milestone:** v1.63 Oracle path-extraction fail-closed
**Started:** 2026-08-23

## Overview

`extractByPath` returned the **entire raw JSON body** as the source value
whenever the configured backing path was absent (or the response was invalid
JSON or a non-object). A mistyped oracle `path` therefore silently stored a
huge raw blob as the field "value" rather than surfacing a configuration
error. The caller (`FetchDataWithValidation`) already treats an empty result
as `ErrInvalidSource`, so the fix is to fail closed by returning empty on
failed extraction.
