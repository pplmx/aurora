# Roadmap: Aurora v1.64 CORS Cross-Origin Key-Exfiltration Hardening

**Status:** Complete ✅
**Milestone:** v1.64 CORS cross-origin key-exfiltration hardening
**Started:** 2026-08-23

## Overview

The router wrapped **every** response — including the `/*` static web-file
server whose HTML embeds `window.AURORA_API_KEY` — in CORS with
`Access-Control-Allow-Origin: *`. Any page the operator visits could issue a
plain cross-origin `fetch('/')` (a CORS-simple GET), read the API key out of
the served HTML, and then drive every `/api/v1` mutation — mint/transfer/burn
tokens & NFTs, lottery/voting state changes, oracle source control — with the
operator's authority. The CORS middleware now echoes only origins listed in the
new `api.cors.allowedOrigins` config (default empty = same-origin only, which
the gateway-served Web UI already relies on) and never emits a wildcard.

The milestone also closes the v1.63 verification gap it exposed:
`TestFetcher_FetchData_Validation_InvalidPath` still asserted the pre-fix
raw-body fallback and left `go test ./...` red on `internal/infra/http`.

## Success Criteria

- [x] CORS never emits `Access-Control-Allow-Origin: *`; a cross-origin request
      for a disallowed origin gets no ACAO header (browser denies the read),
      `Vary: Origin` is set, and preflights still answer 204.
- [x] Configured origins (`api.cors.allowedOrigins`) get their origin echoed so
      a deliberately cross-origin UI keeps working.
- [x] Composition regression test `TestCORS_CrossOriginCannotReadInjectedAPIKey`
      proves a disallowed cross-origin page cannot read the key-bearing HTML
      through the real CORS → injectAPIKey → static-file chain;
      `TestCORS_ConfiguredOriginReadsUI` locks the operator opt-in.
- [x] Stale `TestFetcher_FetchData_Validation_InvalidPath` updated to the v1.63
      fail-closed contract (loopback-free round tripper, both validateJSON
      modes → `oracle.ErrInvalidSource`); baseline `go test ./...` is green.
- [x] `go build ./...` green; `go vet` clean; `gofmt`/`goimports` clean;
      `go test -race` green on config/api/http packages.
