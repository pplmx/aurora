# Roadmap: Aurora v1.13 Observability

**Status:** In progress
**Milestone:** v1.13 Observability
**Started:** 2026-08-23

## Overview

The project plan deferred observability/metrics to "future". v1.13 starts to
collect on that: a minimal, stdlib-only request-observability surface that can
be scraped like Prometheus, without pulling a metrics dependency or changing
the framework. This addresses the recurring "operational readiness" gap cleanly
and testably.

## Success Criteria

- [x] Add a concurrency-safe `internal/metrics` registry (request total,
      per-status counter, and latency histogram) in Prometheus text format.
- [x] Add a chi middleware that records each request's status + latency.
- [x] Expose `/metrics` on the public router so it is scrapeable, plus a route
      regression test.
- [x] Full `go test -race ./...` green with the metrics package in the suite.
